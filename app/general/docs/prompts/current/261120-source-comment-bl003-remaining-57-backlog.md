## BL-001 Windows の cplat_module_get_path が、長いパスと非 ASCII のパスで失敗する

- **現状の事象**: `app/cplat/prod/libsrc/cplat/runtime/module.c` の Windows 側は、`MAX_PATH` (260) の固定長バッファーを使います。パスが UTF-16 で 259 文字以内でも、UTF-8 で 260 [byte] 以上になる場合 (例: 日本語 87 文字以上) は、呼び出し側のバッファーが大きくても `CPLAT_ERR_BUFFER_TOO_SMALL` を返します。260 文字以上のパスは `CPLAT_ERR_UNKNOWN` を返します。公開ヘッダーに、最大長の契約はありません。
- **摘出契機**: 枝番号 059 の調査 (2026-11-20)。
