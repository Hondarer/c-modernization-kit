# 対象となる事柄 最終仕様

ファイル名: `対象となる事柄-design.md` または `案件ディレクトリ/design.md`

最終的に確定した仕様を、対象に合わせた構成で構造的に記述する。議論の推移は含めず、重要な補足情報や意思決定の背景は admonition (注記ブロック) で補う。検討用 Markdown への案内は、先頭のメタ情報だけに記載し、本文には記載しない。

永続的に必要とされる知見や設計判断がある場合は、コード コメントや各種正本ドキュメントへの反映計画 (どの文書・コードへ何を反映するか) も構造的に整理する。反映対象は将来必要となる有意義な仕様を厳選し、作業誤りの訂正経緯や個々の逸脱点・対症療法的な禁止事項はやみくもに盛り込まない。
