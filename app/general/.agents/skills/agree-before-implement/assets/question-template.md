# Q-XXX 質問の短い題名

**Status**

未回答

**Question**

ここに 1 つの判断のみを問う質問を記述する。

**Context**

質問に至った経緯、質問が必要な理由、判断の影響を具体的に記述する。根拠資料や各案の具体例は、質問意図が簡潔明瞭な際には挿入する必要はないが、成果物の具体的な姿を提示したほうが良い場合や、意図不明とされた質問の詳細化では積極的に提示する。必要に応じて Mermaid など、プレーン テキスト以外の書式も許容する。

- **経緯と背景**: 何を調査・設計・実装している中でこの疑問や分岐が生じたのか、現状の事象や課題を記述する。
- **根拠資料**: 根拠となった実際の仕様書、設計書、ソース コードへのリンク (例: [対象ファイル](file:///path/to/file#L10-L25) など) を記載する。
- **現状または判断対象のコード引用**: 現状のコード片や対象箇所の記述例をコード ブロックで引用する。

```text
/* 現状の実装コードや、判断対象となる記述例 */
```

- **各案の具体例・コード比較**: 推奨案だけでなく他の案についても、採用した場合にどのようになるかを具体例やコード ブロックで示し、ユーザーが違いを理解できるようにする。

```text
/* 案 A (推奨) の場合の記述例や振る舞い */
```

```text
/* 案 B の場合の記述例や振る舞い */
```

**Answer**

選択方式: 単一選択

- [ ] A: (推奨) 代表的な選択肢を記述する。
- [ ] B: 別の代表的な選択肢を記述する。
- [ ] C: その他
- [ ] X: 意図不明 (詳細な質問内容に再生成すること)
