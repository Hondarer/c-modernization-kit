# 対象となる事柄 簡易 ADR

ファイル名: `yymmdd-対象となる事柄-lightadr.md` または `案件ディレクトリ/yymmdd-案件概要-lightadr.md`

この文書は、検討で得られた事実、ユーザーの選択とコメント、およびそれらに基づく決定事項を、決定 1 件ごとにまとめた簡易 ADR (Architecture Decision Record: 設計判断の記録) です。正式な ADR ではなく、対案の比較や決定の影響の評価は記載していません。  
各決定の「決定」は、方針が変わるたびに書き換え、常に最新の決定だけを示します。変更の推移は「経緯」に時系列で記録します。

### 背景と課題

何を決める必要があったかを 2 から 3 文で記述します。検討用 Markdown が削除されても意味が通るように、Q の **Question** と **Context** の要旨を記載します。

### 得られた事実

決定の根拠となった事実を、出典 (資料、ソース コード、検証結果) とともに記述します。AI の推測や推奨理由は含めません。

### 決定

現時点で有効な決定を言い切りで記述します。方針が変わった場合はこの記載を書き換え、過去の決定は「経緯」に残します。
