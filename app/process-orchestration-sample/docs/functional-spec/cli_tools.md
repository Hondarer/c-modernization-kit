# コマンド ライン (cli_tools) 機能仕様

## 概要

コマンド ライン機能は、親プロセスの起動、子プロセスの起動、第三者プロセスからの対話・スクリプト制御、および同期 IPC の性能比較ベンチマークを実行するための 4 つのコマンド ライン実行体を提供します。

利用側は、C プログラムから直接呼び出す代わりに、シェルやテスト スクリプトから同一のプロセスとりまとめ機能および同期 IPC 性能計測を実行できます。

## 解決する課題

プロセスとりまとめの動作確認や、異なるトランスポート方式・接続方式 (単発接続と持続接続) の性能比較を行う際に、毎回専用の呼び出しプログラムを作成するのは手間がかかります。

コマンド ライン機能は、親・子・制御・ベンチマークの各役割を独立したコマンドとして提供し、共通のオプション体系と機械可読な標準出力・終了コード規約によって手動検証と自動テストの双方で利用できるようにします。

## 4 つのコマンドの役割

- **親コマンド**: 親プロセスとしてフォアグラウンドで動作し、子 1〜3 を起動・監視します。
- **子コマンド**: 親コマンドから自動起動されるほか、単体検証時に指定子 ID の子プロセスとして直接起動できます。
- **制御コマンド**: 第三者プロセスとして親または子へ 1 回の操作を実行し、状態情報またはエコー バック結果をキー値形式で標準出力へ表示します。
- **ベンチマーク コマンド**: 計測専用の同期 IPC サーバーを同一プロセス内で一時起動し、指定された条件で単発接続と持続接続の往復レイテンシおよびスループットを計測して出力します。

## 出力形式と終了コード

制御コマンドは、状態取得・起動・停止時に子 ID、状態名、PID、累計起動回数、終了コード取得有無、直近終了コードを 1 行のキー値形式で出力します。  
直接エコー バック時は、応答元の子 ID、子 PID、および返却文字列を出力します。

ベンチマーク コマンドは、実行条件のサマリー行に続き、モードごとに平均・p50・p95・p99 レイテンシおよびスループットを 1 行で出力します。

## 適用範囲外

- 対話シェル (REPL) モードや設定ファイルからのバッチ実行
- JSON や CSV などの構造化出力フォーマットの切り替え
- バックグラウンド デーモン化や Windows サービスとしての登録機能
- ベンチマーク結果のファイル保存やグラフ生成

## 前提と制約

- 隔離ディレクトリ空間を指定する場合は、ベース ディレクトリを明示的に指定する必要があります。
- 制御コマンドの実行対象となる親または子が起動していない場合、制御コマンドは通信失敗として非 0 で終了します。
- ベンチマーク コマンドの計測値は実行環境の負荷や OS スケジューリングの影響を受けるため、バックエンド間の比較は同一環境・同一条件で行います。
