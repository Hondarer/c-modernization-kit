# string-catalog-sample

cplat の文字列カタログ機能の利用例です。  
カタログ定義から文字列 ID の列挙とカタログの表を生成し、言語を切り替えながら文字列を組み立てます。

このファイルは、機能ドキュメント群のホームに表示されます。
